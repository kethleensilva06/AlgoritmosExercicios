# Algoritmos Exercícios (refeitos)

Reescrita dos exercícios 1 a 5 do repositório
[`profedsonvieira/AlgoritmosExercicios`](https://github.com/profedsonvieira/AlgoritmosExercicios),
pra estudar lógica de programação e Python básico.

## Como rodar

Precisa do Python 3.10+ (por causa do `match/case` do exercício 5):

```bash
python3 ex01.py
python3 ex02.py
python3 ex03.py   # pede dados pelo teclado
python3 ex04.py   # pede dados pelo teclado
python3 ex05.py   # menu interativo
```

## O que cada um faz

- **ex01.py** — variáveis, contas simples e f-strings.
- **ex02.py** — cálculo de uma compra com desconto, imprimindo um recibo formatado.
- **ex03.py** — mesma ideia do ex02, mas pedindo os dados pelo teclado.
- **ex04.py** — if/elif/else pra decidir se libera a entrada num evento.
- **ex05.py** — menu com 4 jeitos de tomar decisão: if aninhado, if/elif, match/case e match/case com guarda.
